# 삼성전자 다음 거래일 방향 적중률 80% 연구

작성일: 2026-11-10 KST. 대상: 삼성전자 보통주 `005930`, KRX 정규장. 성격: 데이터·알고리즘 선정과 검증을 위한 연구 문서. **모델 학습·실거래·80% 성능 실증 결과가 아니다.**

사용자 요구: “어떤 사이트의 API를 사용하고, 어떤 방식(논문, 알고리즘) … 최소80%”. 추가 답변으로 **상승·하락 방향 적중률80%**를 선택했다.

## 1. 연구 결론

**공식 시세·공시·거시 자료를 시점에 맞춰 결합하고, 단순 기준선과 정규화 로지스틱 회귀부터 XGBoost를 비교하는 방법을 권한다.** 뉴스·반도체 이벤트는 수치 모델의 추가 정보로 검증한다. 전문가 토론과 LLM은 근거 추출·반론·설명을 담당한다.

**80%는 유지할 연구 목표이며 아직 입증되지 않았다.** 80%가 나온 백테스트 하나를 찾는 것으로 완료하지 않는다. 사전에 고정한 기간·모집단에서 보류·실패를 포함해 평가하고, 시간순 외부 검증과 미래 실시간 관찰을 통과해야 한다. 결과가80%에 못 미치면 목표 미달로 보고한다.

Choi·Song(2021)은 KOSPI 지수와 개별 종목을 함께 다룬다. **Table 7의 대상은 삼성전자**이며, 입력은 직전5·10·30일 수익률이다. 그 표에서 비교한 모든 모델·입력 길이 중 최고값은 `1D-CNN, d=10`의54.4%다. 2016~2019년 자료를 사용한36개 시험 구간의 평균이다. 논문은 보합을 하락 쪽에 묶어 이번 연구의 보합 정책과도 다르다. 이 결과는 현재 성능의 상한이나 추천 모델의 기대값이 아니며, 가격 이력만으로 복잡한 모델을 쓰면80%가 된다는 주장을 지지하지 않는 직접 사례다. [원논문 §2·§3·Table 7](https://doi.org/10.29220/csam.2021.28.4.329), [저자 소속 대학 기록](https://pure.ewha.ac.kr/en/publications/is-it-possible-to-forecast-kospi-direction-using-deep-learning-me/)

## 2. 80%의 평가 계약

기존 앱의 `±0.5%` 상승·중립·하락3분류와 명목80% 예측구간은 유지되는 별도 제품 지표다. **이 연구의 이진 방향80%를 그 지표들로 바꾸지 않는다.** 연구안을 앱에 반영하려면 이후 공유 계약·방법 버전을 따로 변경해야 한다. 기존 기준: [제품 명세](../../HERDR-PROJECT.md).

| 항목 | 이번 연구의 제안 |
|---|---|
| 예측 시점 | 대상 KRX 거래일07:40:00 KST까지 자료 마감, 08:00:00 KST까지 공개·동결. 전일 장 마감에서 보면 다음 거래일의 종가 전망 |
| 목표 가격 | 직전 KRX 거래일의 비교 가능한 종가 대비 대상 거래일 확정 종가. NXT·시간외·미국 상장 대체 종목 가격을 섞지 않음 |
| 수익률 | `r_t = C_t / C_(t-1, comparable) - 1`. 분할·병합 등 조정 근거와 가격 공급자 버전을 연결 |
| 실제 방향 | `r_t>0` 상승, `r_t<0` 하락. 보합 `r_t=0`은 학습의 이진 라벨에서 제외하고 `A_all` 분모에는 남겨 정답0으로 처리 |
| 예상 방향 | 사전에 고정한 확률 임계값으로 상승 또는 하락을 선택. 0.5 동률 처리도 미리 고정 |
| 주 지표 | `A_all = 정시 발표된 방향 정답 수 / 사전에 정한 전체 예정 거래일 수` |
| 보류·누락·지연 | `A_all`의 정답 수를 늘리지 못함. 보류·미발표·지연을 분모에서 빼지 않음 |
| 평가 가격 지연 | 완료로 처리하지 않음. 미해결 건수를 공개하며, 해당 창의 최종 성과 판정을 보류 |
| 거래정지·평가불가 | 사전에 정한 공식 사유·시각·건수를 공개. 임의 삭제 금지. 조건부 방향 적중률은 정시 방향 예측·비보합·평가 완료가 모두 충족된 날짜만 분모로 사용 |
| 보조 지표 | 제공률, 보합/평가불가 수, 비보합 전체일의 방향 적중률(보류·누락은 정답0), 상승·하락별 recall, balanced accuracy, 이진 Brier·log loss, 국면별 성적. 확률 지표는 정시 유효 확률·비보합·평가 완료일에서 계산하고 제외 수 공개 |
| 투자 성과 | 별도. 아침 예측으로 이미 지나간 전일 종가에 매수했다고 가정하지 않음. 실행 가능한 주문 시점·수수료·세금·슬리피지가 있어야 수익률을 계산 |

예를 들어250일 중50일만 예측해서40일 맞히면, 선택한 날의 적중률80%, 제공률20%, 전체 예정일 정답률16%다. 이 경우 이 연구의 전체 거래일80% 목표를 달성했다고 쓰지 않는다. 선택적 예측의 정확도–제공률 절충은 [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)의 연구 주제이지만 삼성전자80%의 실증 근거는 아니다.

`A_all`은 시장 방향을 맞히는 능력과 제때 결과를 제공하는 품질이 결합된 **방향 적중 제공률**이다. 순수 조건부 방향 적중률과 이름을 구분한다. `U`는 **정시 방향 예측이 이미 동결됐고 실제 방향만 미확정인 날짜**로 한정한다. 잠정값 `H/N`과 가능한 상한 `(H+U)/N`을 함께 표시한다. 보류·미발표는 가격이 확인돼도 잠재 적중으로 바뀌지 않는다.

초기 종결 정책은 대상일로부터5 KRX 거래일까지 `pending`으로 추적하고, 이후에도 비교 가능한 가격·조정 근거가 없으면 사유와 함께 `closed_unassessable`로 닫는 안이다. 이는 공급 SLA가 아닌 연구 제안값이며 시험 시작 전에 확정해야 한다. 종결된 평가불가는 전체 예정일 분모에 남기고 정답을 부여하지 않는다. 미해결 평가가 있으면 최종 합격을 보류하되 목표 미달·근거 부족 보고는 계속한다. 마감 점수와 사후 가격 정정 점수를 모두 보존하며 유리한 개정만 고르지 않는다. 이 보수적 주 지표는 보류로80%를 만드는 것을 막기 위한 연구 제안이다.

판정 점수는 **최신 공식 가격·기업행사 정정을 모든 날짜에 일관되게 반영한 평가 개정**을 사용한다. 최초 T+5 점수와 당시 판정은 이력으로 보존한다. 나중 정정으로 현재 점수가 바뀌면 합격·미달 판단도 갱신하고 이유·개정 시각을 공개한다. 불리한 정정을 빼거나 옛 유리한 점수를 고르지 않는다. 원래 입력·예측은 변경하지 않는다. 이 정책은 시험 전에 등록한다.

캘린더는 공식 KRX 거래 세션을 기준으로 한다. 임시휴장·공식 일정 변경은 캘린더 개정 근거와 제외 건수를 남긴다. 실제 휴장일은 N에서 제외하고 개별 종목 거래정지는 N에 남긴다. 전향 창은 사전 시작일 이후 실제250거래일로 정의하므로 공식 휴장에 따른 종료일 이동을 허용한다. 성적 때문에 창을 늘리거나 줄이지 않는다.

개발 자료에서는 보합·영구 평가불가·미발표 등 **구조적으로 정답을 제공할 수 없는 날짜의 합집합**을 계산해 `A_all`의 도달 가능 상한을 함께 점검한다. 겹치는 사유를 단순 합산하지 않는다. 이 연구에는 실제 해당 비율의 측정값이 없다. 보합 제외로 학습한 이진 확률은 비보합 조건의 확률로 해석하며 무조건부 상승 확률로 과장하지 않는다.

### 비교할 모델

아래 순서는 현재의 연구 종합 제안이다. 삼성전자에서 우월성이 측정된 순위가 아니다.

1. **기준선:** 항상 상승, 과거 학습 구간 다수 방향, 전일 방향 유지, 과거 방향 빈도 확률. 모두 같은 날짜·가격·마감·보류 규칙으로 평가한다.
2. **M1:** L2 정규화 로지스틱 회귀. 수익률·변동성·거래대금·검증된 수급·가용 거시 변수로 시작한다. 학습 구간 안에서만 결측 처리와 스케일을 학습한다.
3. **M2:** 얕은 XGBoost. 모델 복잡도·early stopping·특징 선택은 내부 시간순 검증으로 결정한다. 결측을 미래 값으로 채우지 않는다.
4. **M3:** M2에 시점이 확인된 공시·반도체 이벤트 특징을 추가한다. 공시·이벤트 없이 가격·허용된 수급·거시 변수를 쓴 M2와 동일 날짜에서 비교해 추가 가치를 확인한다.
5. **보류 후보:** LSTM·Transformer·시계열 foundation model·다중 LLM 투표. 장기 이력·오염 통제·계산 비용에 비해 검증된 추가 이득이 있을 때 별도 후보로 비교한다. 복잡성만으로 채택하지 않는다.

초기 후보 수를 적게 유지한다. 두 boosting 라이브러리를 동시에 넓게 탐색하거나 여러 딥러닝 구조를 무제한 추가하지 않는다. 후보를 늘리면 검색 횟수와 추가 최종 시험 비용을 기록한다.

최선 방향 기준선은 **개발 구간의 시간순 외부 평가**에서 `A_all`로 선택해 최종 시험 전에 하나로 고정한다. 동률이면 항상 상승→학습 구간 다수 방향→전일 방향 유지 순서로 단순한 것을 고른다. 확률 기준선은 학습 구간의 과거 상승 빈도로 고정한다. M1은 이 고정 기준선, M2는 M1과 고정 기준선에 대해 아래 M3와 같은 paired 방향 개선·확률 비악화·제공률 비악화 기준을 개발 구간에서 충족해야 다음 후보로 채택한다. 충족하지 못하면 더 복잡한 후보를 채택하지 않고 그 결과를 보고한다. 최종 후보 선택에 쓰인 모든 외부 평가는 개발 자료이며 최종 시험을 대신하지 않는다.

LLM은 `공시 사실 → 발표 시각 → 공급망 관련 사건 → 반증 자료`를 구조화한다. 방향 확률은 수치 모델이 산출하고 실제 성적으로 보정한다. 동일 모델을 여러 역할로 나눈 합의는 상관된 판단일 수 있으므로 독립 관측이나 성능 표본으로 세지 않는다.

**M3 채택 조건 제안:** 같은 예정일·가격 라벨·재학습 일정에서 고정 M2와 비교한다. 날짜별 적중 차이 `hit_M3−hit_M2`의 의존 반영95% 하한이0을 초과하고, 같은 표본의 Brier 차이 `B_M3−B_M2`의95% 상한은0 이하여야 한다. 전체 예정일 제공률도 M2보다 낮아지지 않아야 한다. 이 기준은 측정된 우월성이 아닌 엄격한 초기 판정안이다. 허용 악화 폭을 두려면 개봉 전에 수치·이유를 별도로 등록한다. 사건이 있는 날만 사후 선택하지 않는다. 여러 후보 탐색은 개발 단계의 전체 후보 원장과 사전 지정한 White Reality Check 등으로 통제하고 최종 후보 하나를 봉인 시험에 보낸다. [원논문·비교 설계](samsung-forecast-2026-11/02-quant-validation.md)

## 6. 시간순 검증과 80% 판정

### 자료 분리

목표 이력은 가능한 범위의 장기 일별 자료다. 예컨대2010년 이후를 요청하되 실제 API 제공 범위·기업행사 품질·당시 자료 확보 상태로 확정한다. 조회되지 않는 이력이 있는 것처럼 쓰지 않는다. 긴 가격 이력이 있어도 과거 뉴스·수급·정정 전 재무가 같은 기간 존재한다는 뜻은 아니다.

- **개발 구간:** 사용 가능한 과거 자료의 앞부분. 초기안은 학습3~5년, 보정6개월, 외부 시험3개월의 rolling/expanding 워크포워드다. 이 길이는 설계값이며 최적값 주장이 아니다.
- **내부 탐색:** 각 외부 시험 이전 자료 안에서만 특징·하이퍼파라미터·보정법을 선택한다. 외부 시험의 성적을 보고 같은 구간을 다시 최적화하지 않는다.
- **역사 lockbox의 자격:** 후보별로 특징·시나리오 설계나 선택에 쓰지 않은 연속250거래일이 실제로 존재할 때만 날짜·접근 이력을 등록하고 한 번만 연다. 최근250일이라는 이유만으로 자격이 생기지 않는다. 이번 연구가2026년 실적·HBM 사건을 참고했으므로 그 기간과 겹치는 역사 자료는 **M3의 개발 자료**로 취급하고 lockbox로 인정하지 않는다. M1/M2도 가격 경로·구간 선택에 대한 연구진의 사전 노출을 점검해야 하며 현재 적격 구간을 확보했다고 주장하지 않는다.
- **전향 관찰:** 별도의 미래250거래일을 무거래 shadow 방식으로 관찰한다. 가격 결과를 알기 전에 예측을 해시·공개 시각과 함께 저장한다. 20일 운영 시험은 파이프라인 점검이며80% 성능 확정이 아니다.
- **업데이트:** 재학습 주기·학습 창·특징·임계값·자료 정정 처리까지 고정한 예측 절차를 시험한다. 중간에 사람이 새 특징·임계값을 선택하면 새 후보로 취급하고 새 시험 창을 사용한다. 매일 오답에 맞춰 방법을 바꾸지 않는다.

적격 역사 lockbox가 없으면 첫 미래250거래일을 미사용 최종 시험, 그 뒤 별도250거래일을 재현 관찰로 등록하는 보수적 대안을 사용한다. M3의 결정적 증거는 동결 이후의 미래 예측이어야 한다. 이 경우 총500거래일 관찰이 필요하다. 실패 후 새 후보를 확인하려면 추가 미사용 미래 기간이 필요하며 같은 창을 재활용하지 않는다. 이는 장기간 관찰 비용이 있는 제안이며 이번에 실행을 시작한 것이 아니다.

실제 날짜와 원본 이력 가용성이 확정되지 않은 현재는 위 구간이 **검증 설계**다. 임의의 달력 기간을 테스트 완료로 표시하지 않는다.

### 미래 정보 유입 방지

`event_time`, `published_at`, `first_seen_at`, `revision_id`, `available_at`, `computed_at`, `input_hash`, 변환 코드·추출 모델 버전, 공급자와 거래소를 저장한다. 실운영의 `available_at`은 검증된 공급 가능 시각과 실제 최초 수집 시각 중 늦은 값이다. `available_at ≤ 정보 마감`인 버전만 사용한다. 역사 자료는 당시 공개본을 복원한 시험과 실제 수집 기록을 구분한다. 공개 당시 가용 시각도 복원할 수 없으면 그 특징의 역사 검증을 제외하고 전향 관찰로 검증한다. 미국 자료는 한국 달력의 같은 날짜로 단순 join하지 않고 마지막 완료 세션·UTC 시각으로 맞춘다.

SEC는 당일 처리한 정정을 당일 저녁 인덱스에 반영하고, 후일 삭제는 이전 daily/feed/oldload에 반영하지 않는다고 안내한다. full/quarterly 인덱스는 토요일 이른 시각 재구축해 PAC 삭제·갱신을 반영한다. 이전 daily/feed/oldload와 현재 full/quarterly 어느 하나도 당시 공개 상태 전체의 완전한 대용으로 쓰지 않는다. 당시 입력 적격성·현재 정정/삭제 상태·내용 복원 가능성·용도별 권리를 분리한다. 허용 범위를 확인한 자료·메타데이터로 당시 버전을 검증할 수 없으면 해당 역사 특징을 미확인/제외로 남기되 예정일·동결 예측은 삭제하지 않는다. 자체 입력이 적격이고 사전등록된 M2 fallback만 적용하며 없으면 보류한다. 이는 특정 공시의 실제 삭제나 보관 허용을 확인한 결론이 아니다. [SEC 확인 범위](samsung-forecast-2026-11/buzz/runs/cycle-20261110-319ad15f64bde8c638fa1f11b872ebc379ad5cdb8196090653385833ab88e09d/data-research.md), [권리·계보 반론](samsung-forecast-2026-11/buzz/runs/cycle-20261110-319ad15f64bde8c638fa1f11b872ebc379ad5cdb8196090653385833ab88e09d/data-rebuttal.md), [SEC 세 범위 재확인](samsung-forecast-2026-11/buzz/runs/cycle-20261113-04e426d5cf07210e4ec5bbdd7a34b7ba84670cd9722231fef7c2cd687a21108e/data-research.md).

07:40:00 KST은 원문·시장 입력 스냅샷을 닫는 시각이다. 이후07:55:00 KST까지 그 스냅샷의 파싱·특징 계산·분석을 수행할 수 있으나 새 원문·새 가격을 가져와 섞을 수 없다. 실제 발표는08:00:00 KST까지여야 한다. 즉 `available_at≤07:40:00`, `computed_at≤07:55:00`, `published_at≤08:00:00`을 별도 검사한다. 처리 실패·시간 초과는 보류·지연 상태로 전체 원장에 남긴다.

특징별 최초/최종 이력·당시 가용 시각·시장/세션·보관/ML 권리·결측을 확정한 뒤 시험 날짜를 봉인한다. 짧은 이벤트 이력 때문에 유리한 기간만 남기는 것을 피하고, M2↔M3의 같은 날짜 비교와 전체 예정일 성적을 모두 남긴다. 재학습 입력·학습 라벨도 **그 재학습 시점까지 알려진 개정**만 사용한다. 이후 정정은 평가·자료의 새 개정으로 연결하며 당시 예측을 다시 쓰지 않는다.

M3의 이벤트가 짧으면 공통 비교 기간과 제외 날짜·사유를 사전에 등록하고 M2도 그 기간에서 평가한다. 긴 M2 성적에서 짧은 M3 성적을 직접 차감하지 않는다. 수집 실패와 확인 결과 ‘새 사건 없음’을 구분한다. 이벤트 결측 때 M2로 돌아가게 한다면 그 fallback도 시험할 M3 절차에 포함하고 횟수를 공개한다. 권리 확인은 원자료 열람 외에 모델 입력·사건 라벨·파생값 보관까지 다룬다. 이 조건은 M2의 수급·거시 변수에도 적용한다.

학습 라벨의 확정 시점이 시험 예측 마감과 겹치면 해당 학습 샘플을 제거한다. 5·20일 목표를 추가하면 라벨 구간이 겹치는 전부를 purge한다. 후행 자료를 학습에 넣는 분할에서는 경계 embargo도 설계한다. 단순1일 예측에 임의의 긴 embargo를 붙이는 대신 실제 라벨·공급 지연을 기준으로 간격을 정한다. scaler·imputer·특징 선택·보정도 모두 학습/보정 구간 안에서만 적합한다.

현재 LLM으로 과거 공시를 읽는 시험은 학습 데이터 오염 가능성이 있다. 시점이 검증된 모델·자료를 확보하지 못하면 텍스트 포함 역사 성과를 핵심 성능 증거에서 분리하고, 모델 버전을 고정한 이후의 미래 예측으로 평가한다.

### 관측80%와 통계적 근거

다음은 실제 주가 실험이 아닌 계산 예시다. 독립 Bernoulli 가정의 양측95% Wilson 구간을 사용했다. [NIST 공식](https://itl.nist.gov/div898/software/dataplot/refman2/auxillar/agrecoul.htm), [원 계산값·가정](samsung-forecast-2026-11/04-calculation-examples.json)

| 정답/전체 | 관측 적중률 | 95% 구간 하한 | 해석 |
|---|---|---|---|
| 16/20 | 80% | 58.40% | 짧은 관찰로80% 능력을 입증하지 못함 |
| 80/100 | 80% | 71.12% | 관측값과 모집단 성능 근거는 다름 |
| 200/250 | 80% | 74.60% | 250일이어도 관측80%만으로 충분하지 않음 |
| 215/250 | 86% | 81.15% | 독립성 가정의 설명 예시이며 실제 주가 합격 보장 아님 |

최종 판정에는 시간 의존성을 고려해 날짜 블록 단위 부트스트랩을 사용한다. 초기 제안은 stationary bootstrap 평균 블록 길이10거래일·재표집10,000회, 길이5·20일 민감도를 사전에 정하는 것이다.80% 하한을 넘는 유리한 길이만 선택하지 않는다. 선택 날짜만 압축하지 말고 보류·누락·기준선까지 포함한 전체 날짜 원장을 재표집한다. 이는 정상성·의존 구조 등의 가정이 필요한 추론이며 모든 미래 시장의 보장은 아니다. 원문 근거와 가정은 [R2 §4](samsung-forecast-2026-11/02-quant-validation.md)에 연결한다. 단일 종목의 여러 모델·특징을 독립 표본으로 늘리지 않는다.

구간은 양측95% percentile 부트스트랩의2.5·97.5백분위로 고정한다. ‘95% 하한’은 그 양측 구간의 하한이다. 주 블록 길이10에서 통과해도5·20 중 하나에서80% 하한 또는 paired 개선 조건이 충족되지 않으면 더 강한 통계적 주장을 보류한다. 비교 기준선은 개발 구간에서 이미 고정한 하나를 사용한다. 이 규격의 적절성과 검정력은 개발 자료에서 점검하고 최종 개봉 전에 등록한다.

개발 검증의 사전등록에는 아래 최소4항목을 구체적으로 적는다. 이는 기존 적절성·검정력 점검을 명료화한 연구 제안이며 실제 등록 완료나 통계법 채택을 뜻하지 않는다.

| 사전등록 항목 | 필요한 내용 |
|---|---|
| 검증 대상·자료 | 고정 예측열의 조건부 추론 검사와 추출·재학습·후보 선택을 다시 수행하는 전체 절차 검증을 구분. 실제/가상 자료, 추론 대상, PIT·권리·가용 기간·lockbox 자격을 명시. 재학습 방식(rolling/expanding/fixed)·손실함수·내부 선택에 적용할 검정·정리·가정과 개발 점검 근거를 함께 등록하고 대응 미확인이면 통계적 승격 보류 |
| 반복·오류 처리 | 동일 날짜의 후보·기준선·결측·보류·M2 fallback과 산업 사건의 재인용·revision·단계·만료 규칙을 명시. 외부 모의 반복 R과 내부 bootstrap B를 구분하고 퇴화·실패 반복을 삭제하지 않음 |
| 주장·판정 | 구간 포함률,80% 경계 오류율, 후보 가족 오류율·paired 최소 개선에서의 검정력을 구분. 각 허용폭·검정력·Monte Carlo 표준오차(MCSE) 정밀도를 결과 확인 전에 고정 |
| 실패·보고 | 누수·부적격 입력·분모 삭제는 검증 무효, 가정/표본 부족·퇴화는 통계적 승격 보류, 관측 목표 미달과 NOT_RUN은 별도 보고. 전체 예정일·조건부 표본과 제외 사유를 공개 |

고정열 검사는 추출·재학습·선택의 불확실성 전체를 검증하지 않는다. 관측하지 않은 산업 모수와 실제 시장 오류율·검정력은 UNKNOWN으로 남긴다. 가상 민감도·작은 MCSE가 시장의 검정력이나 자료 권리를 입증하지 않는다. 제목4개만 채우거나 허용폭·처리 규칙이 미정이면 등록 미완료다. 이미 구체적으로 등록한 항목은 중복 추가하지 않는다.

내부 선택에는 산업 사건의 추출·연결·revision·단계/만료·추출 버전·fallback 규칙의 개발 선택도 포함한다. 검정 이름이나 rolling 전환만으로 가정 충족을 인정하지 않는다. 고정열 조건부 검사만 가능하면 전체 절차의 일반화 검증은 미완료이며, 희소·장기 유지 사건의 가정 대응·유한표본 근거가 없으면 통계적 승격을 보류한다. 근거는 시간 의존·퇴화 표본의 [가상 반례와 원문 확인 범위](samsung-forecast-2026-11/buzz/runs/cycle-20261110-9ecb6f2e506723c98bea23a56d4a7faed09d5fc196ceed01b5bb4aecbcea0917/quant-research.md), [최소4항목 제안과 반증 조건](samsung-forecast-2026-11/buzz/runs/cycle-20261110-9ecb6f2e506723c98bea23a56d4a7faed09d5fc196ceed01b5bb4aecbcea0917/quant-rebuttal.md), [자료가용성 반론](samsung-forecast-2026-11/buzz/runs/cycle-20261110-9ecb6f2e506723c98bea23a56d4a7faed09d5fc196ceed01b5bb4aecbcea0917/data-rebuttal.md), [산업 질문 응답과 잔여 미등록](samsung-forecast-2026-11/buzz/runs/cycle-20261110-9ecb6f2e506723c98bea23a56d4a7faed09d5fc196ceed01b5bb4aecbcea0917/industry-answer.md)다. 반례는 실제005930 성적이나 전체 승격 규칙의 오합격률이 아니다. SPA·자동 블록 길이 선택의 즉시 도입과 rolling 전환만으로 정상성을 인정하는 안은 채택하지 않는다. 기존 양측95% 규격·블록 민감도·분모·모델 순서·lockbox 계약을 유지한다. 실제 등록·오류율/검정력 실행 결과는 여전히 미검증이다.


| 판정 | 사전에 요구할 조건 |
|---|---|
| 관측 목표 달성 | 적격 미사용 시험과 별도 전향/재현 시험에서 각각 `A_all≥80%`, `pending=0`. 적격 역사가 없으면 위의 두 미래 창을 사용. 오염·임의 분모 변경 없음 |
