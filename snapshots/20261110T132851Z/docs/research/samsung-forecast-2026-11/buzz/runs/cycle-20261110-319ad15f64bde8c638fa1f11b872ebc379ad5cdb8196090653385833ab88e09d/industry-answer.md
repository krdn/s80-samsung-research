## 1. R1 질문 — 실제 등록과 사건 구분

**직접 답: 실제 등록 완료가 아니다.** 현재 입력에는 동일 사건·revision·단계·유지/만료를 구분할 원칙과 제안이 있다. 배당·TSMC 사건에 적용할 만료 기간/조건·정정 중요도·충돌 우선순위·발동 상세를 고정한 등록 근거는 확인하지 못했다. 기준 문서의 최소4항목 요구를 실제 등록표·구현·실행 완료의 증거로 사용하지 않는다.

**입력·surprise 직접 답:** 가용시각·당시 버전·용도별 권리·사건 규칙이 필요한데 없으면 해당 역사 특징의 적격성을 미확인/제외로 남긴다. 당시 합법적인 기대 자료가 없으면 surprise를 생성하지 않는다. 회사의 직전 발표 대비 변화는 별도 특징이며, 그 적격성도 별도로 확인해야 한다. 현재 본문을 읽은 사실이 과거07:40 사용 가능성이나 모델용 이용권을 입증하지 않는다.

**만료 직접 답:** 예정일 도래·정정 관찰·새 URL·새 수신만으로 신호 만료를 재시작하지 않는다. 기존 결의 사실의 연구 기록을 보존하는 것과 일별 예측 신호를 활성 상태로 유지하는 것은 별개다. 유지/만료 규칙이 미등록이면 기존 신호를 무기한 유지하지 않고 해당 신호 사용을 보류한다. 실제 단계 전환도 적격 증거와 사전등록이 있어야 후속 입력으로 처리할 수 있으며 과거 입력을 덮어쓰지 않는다.

**최소 메타데이터 직접 답:** 공개 식별자·시각·해시도 보관 허용을 일괄 가정하지 않는다. 허용 범위를 확인한 후 그 범위에서 근거를 연결한다. 미확정이면 새 원문·파생 라벨·메타데이터의 모델용 보관 적격을 승격시키지 않는다. 이번 연구용 링크·한계 기록이 실제 데이터셋용 수집/보관 허락을 대신하지 않는다. 이는 특정 자료의 법적 허용·금지 결론이나 과거 기록 삭제 지시가 아니다.

## 2. R2 질문 — 공식 출처 충돌에서 유지·변경·보류

**직접 답:** 현재 입력은 실제 충돌이 확인된 배당/TSMC 사례를 제공하지 않는다. 아래는 충돌이 발생할 때의 판단 경계를 설명한 제안이다. 새 자동 우선순위·만료 일수·수치 문턱을 확정하지 않는다. ‘공식’·‘더 최신 URL’·‘더 많은 출처’만으로 어느 진술이 우선하는지 정하지 않는다.

| 처리 | 허용할 판단 범위 | 미확인으로 남길 것 |
|---|---|---|
| 확인 사실 유지 | 대상 회사·기간·행위·범위를 대조하고 서로 충돌하지 않는 사실은 출처·확인 범위와 함께 유지. 기존 입력/예측 이력 보존 | 사실 보존을 신호의 지속 활성화·반대근거 무시로 확대하지 않음 |
| 확인 내용 변경 | 같은 사건 계보임이 확인되고 공식 정정 또는 실제 행위의 명시적 근거로 달라진 내용을 확인하면 새 확인 기록으로 연결 | 변경 시각 불명이면 과거 어느 예측부터 반영됐어야 하는지 확정 불가. 신호 반영은 가용성·권리·사전등록을 충족해야 하며 과거 입력 소급 금지 |
| 충돌 부분 보류 | 단계·실행액·대상 범위가 모순되거나, 정정 중요도/전후 내용/시각이 미확인이면 해당 속성 및 그 속성을 요구하는 신호 사용 보류 | 부분 집행을 전액 완료로 통합하거나 미확인 차이를 연구자 재량으로 해소하지 않음. 계보 연결 자체가 불명인 경우에는 연결도 추정/미확인으로 남김 |

**배당 확정/미확정:** research에서 확인한 것은 이사회 결의·주당액·총액·기준일·지급 예정일이다. 지급 예정은 실제 지급을 뜻하지 않는다. 현재 공시의 ‘지급 예정’과 나중 문서의 ‘지급 완료’는 행위·대상·범위·시각이 확인되면 단계 전환일 수 있지만, ‘일부 지급’과 ‘전액 완료’가 충돌하면 해당 완료 범위를 미확인으로 남긴다. 이번 실제 지급 증거와 충돌 우선순위 등록은 없다. 예정일만 지난 것으로 완료를 생성하지 않는다.

**TSMC 확정/미확정:** research에서 읽은 것은 경쟁사의 특정 보고월 연결매출 발표다. 삼성으로의 전달 가설에는 삼성 고객/제품/계약·출하/손익의 연결 근거가 별도로 필요하다. 그 연결과 순효과 부호는 이번 미확인이다. 경쟁사 실적 증가가 산업 수요 확대와 경쟁 강화 두 경로를 가질 수 있으므로 삼성 수혜·방향·확률로 확정하지 않는다. 내부거래·공유 고객·여러 매체 재인용을 독립 효과로 합산하지 않는다. 컨센서스와 시각도 미확인이라 surprise·과거 아침 적격을 만들지 않는다.
