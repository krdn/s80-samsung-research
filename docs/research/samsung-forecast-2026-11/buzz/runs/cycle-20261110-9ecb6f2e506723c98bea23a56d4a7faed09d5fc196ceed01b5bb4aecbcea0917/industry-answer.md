## 2. R2 질문: 사건·revision·유지 상태의 최소 증거

다음은 **제안 규칙**이다. 현재 모든 사건에 이 증거를 확보했거나 규칙을 구현했다는 뜻이 아니다. 문서 수와 독립 사건 수는 다르며, 새 revision·새 단계가 있어도 독립 통계 표본이 되는 것은 아니다.

**최초 가용시각 답:** 각 적격 버전의 공개·공급 가능 시각과 실제 최초 수신 시각 중 늦은 시각을 사용한다. 확인된 버전 집합 안의 최초이지 시장 전체 최초라고 주장하지 않는다. 날짜만 있거나 현재 HTTP 메타데이터만 있으면 당시07:40 적격을 확정하지 않는다. 뒤늦은 전문의 새 조건을 앞선 발표 시각에 붙이지 않는다.

**보류 답:** 현재 내용 자체는 확인돼도 공개/가용시각·내용 변화·권리가 미해결이면 해당 역사 특징 입력을 제외한다. 전향 사용도 적격 증거·규칙이 있어야 한다. 전체 예정일 행은 유지하며 사전 고정되고 입력 적격인 M2 fallback이 있을 때만 그 절차를 쓴다. 없으면 보류/누락으로 기록한다. 오늘 허용 기록을 시작했다는 사실은 오늘의 시장 신규 정보라는 뜻이 아니다.

| 실패·보고 | 불법적 입력이라는 단정 대신 권리 미해결·시각 부적격 등 확인 상태를 보고. 누수·분모 삭제는 검증 무효, 표본/가정 부족은 승격 보류, 관측 미달과 NOT_RUN은 별도. 소수 사건 진단을 예정일 N의 대체로 쓰지 않음 |

같은 날짜의 M2/M3와 예정일 원장을 유지한다. 사건일만 고른 적중률로 A_all을 바꾸지 않는다. Brier의 공통 정시 유효·비보합·평가 완료 표본과 제외 수도 보존한다. 사건/국면 수가 작으면 일수가250일이라는 이유로 근거 충분을 선언하지 않는다. 새 사건을 가공해 이력을 늘리거나 유리한 시험 창으로 교체하지 않는다.

**반론·철회 조건:** 네 제목만 추가하고 내용이 미정이면 등록 완료가 아니다. 기존 등록에 이미 구체적 내용이 있으면 중복 추가는 NO_CHANGE다. 가상 스트레스 시험의 성공은 특정 공급자 권리·과거 시각이나 실제 시장 검정력을 해결하지 않는다. 개발 검증과 적격 미사용 최종 시험·전향 관찰을 대체하지 않는다. SPA·자동 블록 선택을 즉시 도입하지 않으며 rolling 전환만으로 정상성 충족을 주장하지 않는다.

## 4. R1/R2 간 질문의 확인 답과 잔여

- **R1→R2:** quant-rebuttal은 고정열/전체 절차 대상, 동일 날짜의 상태·fallback, 실패/보류/NOT_RUN 구분에 원칙적으로 답했다. 다만 R1 rebuttal을 입력으로 받은 답변은 아니므로 상호 확인·합의로 쓰지 않는다. 실제 날짜 벡터 구성·생성 조건·허용폭·fallback 상세는 미등록이다.
- **R2→R1:** data-rebuttal은 목적별 권리·허용 메타데이터 확인, 권리 미해결 라벨의 채택 보류, 역사 제외/전향 조건을 설명했다. 특정 자료의 최소 허용 메타데이터 범위를 확정한 답은 아니다. 적격 M2 fallback/보류의 원칙은 R2에 있지만 실제 공급 계약·허용 범위·발동 규칙 완료는 미해결이다.
- **남은 쟁점:** 산업 규칙의 구체적 등록과 실제 자료 적격성, 검정력 충분성은 어느 문서의 동의로 해결되지 않았다. 이번 답변은 이 원칙을 연결한 R3 판단이다. 상대가 이후 이 답에 동의했다고 기록하지 않으며 추가 왕복을 자동 생성하지 않는다.
