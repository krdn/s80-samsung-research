# 교차토론 질문

입력: 각 역할의1차 보고서와 [통합 초안](../samsung-direction-80-research-2026-11.md). 토론 답변은 각 역할이 자기 반박 파일에 작성한다. 주 책임자는 답변을 대신 창작하지 않는다.

## 쟁점

1. **목표 분모:** 통합안의 `A_all=정시 방향 정답/전체 예정 거래일`은 보류·지연을 숨기지 않는다. 이것을 시장 방향 능력과 운영 품질을 결합한 지표라고 표시할 필요가 있는가? 보합·거래정지·미평가를 어떻게 표시해야 목표가 바뀌지 않는가?
2. **검증 규모:** 역사 lockbox250일과 별도 미래250일은 설계값이다. 관측80%와 통계적80% 주장, 블록 부트스트랩 가정, 반복 탐색·중간 종료 위험을 충분히 구분했는가?
3. **자료 현실성:** KRX 공급시점, KIS 조정 옵션·정규장 범위, DART 접수시각, ECOS vintage, FRED/TrendForce의 이용 제한 때문에 특정 특징을 실제로 만들 수 없는가? 제안이 권리·시점 문제를 해결한 것으로 과장했는가?
4. **산업→가격:** HBM/메모리/파운드리·환율·수급의 전달 경로가 다음날 부호 예측력을 입증하는가? 이미 반영된 기대, 장후 새 정보, 동시 상관, 컨센서스 없는 surprise를 어떻게 반증하는가?
5. **알고리즘:** 로지스틱→XGBoost→이벤트 추가 순서의 장단점과 기각 조건은 무엇인가? 다중 LLM 토론을 성능 앙상블로 착각할 여지가 있는가?

## 답변 방식

한국어로 핵심 반박3개 이내, 동의2개 이내, 상대에게 답할 질문1~2개, 통합안 수정문을 제시한다. 각 항목은 상대 파일의 제목·문구와 직접 연결한다. 제안·합의·실측 증거를 구분한다. 새로운 광범위 조사·에이전트·앱 변경은 하지 않는다. 반박이 없으면 억지로 만들지 말고 남은 가정을 적는다.

R1/R2는 서로의 보고서와 통합안을 먼저 토론한다. R3는 독립1차를 제출한 뒤 두 보고서와 반박을 읽고 산업 관점에서 답한다. 필요한 상대 답변은 동일 pane에서 후속 턴으로 받는다. 동시 작업자2명 상한을 지킨다. 최종 쟁점 채택/기각과 이유는 주 책임자가 실제 답변에 근거해 기록한다.
