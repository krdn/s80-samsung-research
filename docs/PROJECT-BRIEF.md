## 개발 계약과 재개 지점

01~07의 로컬 구현·검증·비공개 전달 결과는 STATE.md와 verification/acceptance.md에 연결한다. 재개는 공식 API 보안 입력·실호출·공식 캘린더·조정 근거 검증부터 진행한다. 실제 원문 분석과 장기 관찰은 별도 미완료 조건이다.

실제 가격·공시 계정·거래 캘린더·08시 실예약·장기 관찰은 아직 NOT_RUN. 이 미완료 조건을 데모 통과로 바꾸지 않는다. 별도 사용자 답변 없이 비용 발생·공개·배포·자동 승격하지 않는다.

기술·예외는 `research/04-decision.md`. 실행 상태·주 모델·작업 소유권은 `STATE.md`. 하위 작업자는 두 HERDR 문서·이 문서·작업 계약과 실제 gon-web-engineering 지침을 읽는다. 현재 주 책임자는 t3m, 환경변수 terminal 불일치에 주의한다.
